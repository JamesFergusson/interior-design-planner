# Interior Design Planner

Ask Claude to plan a room ("help me plan my living room") and it builds you an interactive planner: real product
options for each part of the room, quantities and costs, a budget bar, a shopping schedule, a link inbox, and a
button that opens ChatGPT with a description of the room to visualise it.

Later, ask Claude to "process my room planner inbox", "find a cheaper option for the rug", or "update my room
planner".

Source, tests and instructions: https://github.com/JamesFergusson/interior-design-planner
